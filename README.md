# Stackd

A transfer-planning tool for California community college students: what you still need, and where you can take it.

Unofficial planning tool. Not affiliated with ASSIST, the UC, the CSU, or any college.

Developed by Ryan Saleh, Shikhar Sisodia, Abyan Kashif, and Antonio Avila.

Project docs are in `docs/`. Start with `docs/README.md`.

- Website (Privacy, Terms, Support): https://joinstackd-chi.vercel.app
- iOS app: a Capacitor project in `ios/`, prepared for the App Store. The remaining Mac steps are in `docs/ios-app-store-handoff.md`, and the listing text is in `docs/app-store/listing.md`.
- Support: joinstackd@gmail.com
