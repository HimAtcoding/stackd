# Explore batch 2a: Cal State majors to check by hand

Filled in by Abyan on 2026-11-08 from each campus's 2026-27 catalog, opened in a browser. A "(todo)" degree has a row with a todo in the major's file.

These 17 Cal State catalogs showed a human-verification check to the automated lookup for Explore batch 2a, so nobody has looked at them yet. A blank row means not checked. It doesn't mean the campus lacks the major.

For each campus, open its current 2026-27 catalog and fill in the row:

- **Offers a matching bachelor's?** Yes or no. The line above each table says which degree names match. Adjacent majors don't count: Biochemistry, Microbiology, Kinesiology, Accounting, Finance, Marketing, Journalism, Public Relations, Business Economics and Statistics.
- **Exact degree name.** As the catalog prints it, with the letters, like Psychology, B.A. If a campus has both a B.A. and a B.S., list both, with a link for each. Concentrations aren't separate degrees.
- **Catalog URL.** The page for that degree, not the department's home page.

Each yes then becomes a row in that major's file, in the same shape as the rows already there.
